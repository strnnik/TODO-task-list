TODO Task List - Консольное приложение на C++

Описание проекта:
Консольное приложение для управления персональными задачами с системой пользователей, хранением данных в бинарных файлах и поддержкой CRUD-операций.

Основные функции:
1. Управление пользователями
2. Регистрация нового пользователя
3. Авторизация в системе
4. Разделение прав доступа (обычный пользователь/администратор)
5. Безопасное хранение паролей

Управление задачами:
1. Создание новых задач
2. Просмотр списка задач
3. Редактирование существующих задач
4. Удаление задач

Система хранения данных:
Бинарное хранение для эффективности (в разработке)

Технические особенности:
Язык: C++20

Хранение данных: Бинарные файлы
Безопасность: Хэширование паролей
Архитектура: Модульная, объектно-ориентированная
